# Reading Digest

A personal learning repository for reading and comprehending technical books with AI assistance.

## Purpose

This repository documents my journey reading technical books chapter by chapter, with the help of an AI reading buddy (Claude via Cursor). The goal is to deeply understand each chapter through active questioning, summarization, and critical thinking.

## Repository Structure

```
reading-digest/
├── CLAUDE.md                    # AI workflow instructions
├── README.md                    # This file
└── [Book-Name]_[Author]/       # One folder per book
    ├── INFO.md                  # Book metadata and table of contents
    └── reading.log              # Q&A session records
```

## How It Works

1. **Start Reading**: Pick a book and read chapter by chapter
2. **Ask Questions**: Work with the AI reading buddy to clarify concepts
3. **Write Summaries**: After each section, write down what you learned
4. **Deep Dive**: Answer probing questions to test and deepen understanding
5. **Track Progress**: All Q&A is logged chronologically in `reading.log`

## Current Books

## Why This Approach?

- **Active Learning**: Questioning and summarizing improves retention
- **Comprehensive Understanding**: Probing questions reveal knowledge gaps
- **Documentation**: Create a searchable record of learning journey
- **Reflection**: Track how understanding evolves over time
